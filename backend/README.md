#  Full-stack Task Management System (Todo App)

A complete Full-stack Todo application built with modern technologies to ensure high performance, security, and a seamless user experience.


##  Tech Stack

| **Frontend** | React, TypeScript, Vite, Tailwind CSS, Lucide Icons |
| **Backend** | NestJS (Node.js Framework), TypeScript |
| **Database** |PostgreSQL |
| **Version Control** | Git & GitHub |
